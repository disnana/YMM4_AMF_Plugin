# YMM4 Radeon (AMF) v0.1.1

Disnana Project / 開発: [tp-li-dev](https://github.com/tp-li-dev)

実機で動作確認したAMF出力経路（P1）を採用した更新です。H.264 / HEVCとAAC音声に対応し、実験用のVideoProcessor経路（P2）は含みません。

## v0.1.0からの変更

- 実測結果に基づき、新規設定の所有テクスチャプールを4枚から6枚へ変更しました。4 / 6 / 8枚の選択は維持しています。
- 出力検証に全デコード、フレーム数・順序、BT.709 limitedのメタデータ、映像と音声の長さの比較を追加しました。
- 終了処理の「Video codec header not found」で、それ以前のエラー内容を上書きしないようにしました。
- 管理プラグインのビルド後に、管理DLLとネイティブDLLを`artifacts/bin`へ自動配置します。
- P2は速度向上を確認できなかったため廃止し、比較結果を開発資料に残しました。

## 確認した範囲

RX 6800 XTでH.264 / HEVC各120フレームとAAC音声の出力、全デコード、フレーム順序、色メタデータの検証に成功しています。YMM4の実プロジェクトではH.264出力と再生を確認済みです。HEVCのYMM4実プロジェクト、長時間反復、キャンセル、複数GPUでの検証は今後の課題です。

## インストール・更新

YMM4を終了し、添付の`YMM4-Radeon-AMF-v0.1.1.ymme`を開いてインストールしてください。手動更新の場合は`AMFPlugin.dll`と`AmfNative.dll`を必ずセットで更新してください。P2試用版からの更新では、実験機能のチェックボックスがなくなります。

配布物の検証用にSHA-256ファイルも添付しています。YMM4本体のDLLは配布物に含めていません。
