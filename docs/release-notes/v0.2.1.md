# YMM4 Radeon (AMF) v0.2.1

Disnana Project / 開発: [tp-li-dev](https://github.com/tp-li-dev)

動画出力の推奨設定を更新しました。所有テクスチャプールを8枚にし、出力回収の待機最適化を既定で有効にしています。出力設定の「推奨設定」ボタンでこの組み合わせに戻せます。「比較用の従来設定」ボタンでは、従来の6枚・待機最適化OFFに切り替えられます。どちらのボタンもコーデック、画質、ビットレート、診断設定は変えません。変更は次の書き出しから適用されます。

RX 6800 XTでの隔離試験では、1080p・H.264・900フレームの出力を同じ条件で各4回比較し、最終化まで含む中央値が358.20 fpsから406.16 fpsになりました。比較した映像と音声を復号したデータは一致しました。描画済みフレームを使う試験の結果であり、YMM4の実プロジェクトや別のGPUでも同じ改善を得られるとは限りません。

通常は既定の「標準」画質を推奨します。高品質設定は処理時間が増えるため、必要な場合に出力結果を比較して選んでください。

## 更新方法

1. プロジェクトを保存し、YMM4を終了します。
2. Assetsの`YMM4-Radeon-AMF-v0.2.1.ymme`を開いてインストールします。
3. YMM4を再起動し、短い区間を別名で出力します。冒頭と末尾の映像・音声を再生して確認してください。

手動更新する場合は`AMFPlugin.dll`と`AmfNative.dll`を同じパッケージからセットで更新してください。設定の永続保存は未実装のため、YMM4再起動後は既定の推奨設定に戻ります。
