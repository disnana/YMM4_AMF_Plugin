# AMF入力満杯待機の実測（2026-09-18）

## 結論

`AMF_INPUT_FULL`後の固定`1 ms sleep`を、圧縮済み出力の完了通知と10 ms fallbackで待つ方式へ置き換えても、RX 6800 XTでは有意な速度向上を確認できなかった。pool 16では通知版が0.46%低下、pool 32では0.12%向上。投入スレッド併用時は0.05〜0.06%向上で、いずれも試行間変動の範囲と判断する。

pool 32では通知版が短い周期で起きるため、AMFへの再投入回数が固定待機の約6.4倍になった。総待機時間と全体速度はほぼ変わらない。CPU・GPU・メモリのバランス改善を示す結果ではないため、設定は既定OFFのまま、通常利用には推奨しない。

## 実装した比較経路

- OFF: 従来どおり`AMF_INPUT_FULL` / `AMF_NEED_MORE_INPUT`後に`sleep_for(1 ms)`。
- ON: `SubmitInput`前にgenerationを取得し、圧縮済み出力通知まで待つ。通知欠落・ドライバー差への有限fallbackは10 ms。
- AMFの入力Surface解放通知は診断カウンターにだけ記録する。Surface解放はAMF入力キューの空きを保証しないため、起床条件にはしない。
- ON専用の追加exportを使い、古い`AmfNative.dll`との混在を明示エラーにする。OFFは従来ABIを通る。
- 画質、bitrate、色変換、GPUコピー数、テクスチャ枚数、mux方式は変更しない。

## 条件

- GPU: AMD Radeon RX 6800 XT
- 1920×1080 / 60 fps / 900 frames / H.264 / Balanced
- 入力解放回収ON、出力回収待機最適化ON
- pool 16 / 32
- 投入スレッドOFF / ON
- 各タイミング条件4回、順序を反転したAB/BA。タイミング後に各条件1回のプロファイル。
- 計時中にデコード検証を並走させず、ゲーム終了後にGPU Engineカウンターが無負荷であることを確認。
- 外れ値は破棄していない。YMM4プロジェクト全体ではなく、実際のAMF DLLへ同一の合成D2Dフレームを渡す隔離測定。

VALORANT実行中に開始してしまった先行セットは途中停止し、`INVALIDATED_BY_CONCURRENT_VALORANT.md`を置いて性能評価から除外した。本節の数値は別ディレクトリで取り直した結果だけを使う。

## 待機の内訳

pool 16では両方式とも`SubmitInput`再試行は0回だった。この条件では設定が定常経路へ作用しておらず、小さい速度差は通知カウンター等を含む試行間変動である。

| pool 32 | 再試行 | 待機合計 | 1回平均 | 通知起床 | timeout |
| --- | ---: | ---: | ---: | ---: | ---: |
| fixed | 134 | 1738.93 ms | 12.98 ms | 0 | 0 |
| signal | 861 | 1684.72 ms | 1.96 ms | 861 | 0 |
| worker-fixed | 134 | 1952.82 ms | 14.57 ms | 0 | 0 |
| worker-signal | 874 | 1899.04 ms | 2.17 ms | 874 | 0 |

Windows上の`1 ms sleep`はこの実測で約13〜15 msまでまとまって休み、その間に複数出力が進んだ。通知版は約2 msごとの出力で起きるが、その時点でも次の`SubmitInput`が満杯になることが多く、約6.4倍再試行した。固定待機の粗い周期を細かくしても、エンコーダーの定常スループットは増えなかった。

単独プロファイルのCPU時間は試行間変動とFinalize外れ値が大きく、CPU削減の根拠には使わない。メモリ量、所有テクスチャ数、コピー数は実装上変更していない。

## 判断

この方式は、固定sleepによる長い停止を観測可能な通知待機へ変える診断価値はある。しかしRX 6800 XTの今回条件では速度・CPU・メモリの総合改善を確認できず、再試行コストが増えた。製品の既定値や自動チューニングには採用しない。

次に進めるなら、sleepの置換を続けるより、GPU timestampでCopy/色変換/encode実行を分け、YMM4実プロジェクトのRender供給間隔とVideo Codec使用率を同じclock/frame IDで対応付ける方が優先度は高い。本オプションの実YMM4 GUI E2Eと長時間出力は未実施。
