   - Source: https://github.com/GPUOpen-LibrariesAndSDKs/AMF

     driver distribution.

3) YukkuriMovieMaker v4 (YMM4) and host-provided assemblies
   - Source: https://manjubox.net/ymm4/
   - Usage: The plugin references YMM4, SharpGen.Runtime, and Vortice assemblies
     from the user's YMM4 installation at build/runtime.
   - Distribution: These assemblies are not included in the .ymme package.
     Consult YMM4 and each component's accompanying terms and notices.

4) Microsoft Windows components and Visual C++ runtime
   - Usage: Windows Media Foundation supplies AAC encoding, and the native
     plugin depends on Windows system libraries and the Visual C++ runtime.
   - Distribution: Not included in the .ymme package. Obtain required runtime
     components through Microsoft or the supported host installation.

5) FFmpeg / ffprobe (optional validation tools)
   - Usage: Development scripts invoke external tools to validate completed
     output. The AMF plugin does not invoke or link FFmpeg for encoding.
   - Distribution: Not included in the .ymme package. Follow the terms of the
     particular FFmpeg build obtained separately.
   - The FFmpeg sentence in the upstream AMF license reproduced below refers
     to the AMF SDK distribution. This plugin uses AMF public headers, not the
     SDK's FFmpeg components.

6) NVIDIA NVENC SDK (legacy source only)
   - Usage: The original NvencNative / NVEncVideoWriterPlugin projects remain
     in the source tree. Building those projects requires NVIDIA's SDK and
     compliance with its terms.
   - AMF package: NVIDIA SDK headers, runtime, and legacy NVENC binaries are
     not used by the AMF build scripts and are not included in the .ymme.
